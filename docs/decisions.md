D10 uses only 2044, 2047, 2050, so results are not expected to change.
- SMR value and net value (03g, 03h; D38), for later reflection. What was found on 29 Oct at `0c0ea27`: `valnew` covers only capacity built in year t (`report.gms` L1043-1044), so the SMR appears only in 2044; its values are one year of service at that region's marginal prices with the SMR already built (`val_load` L1060-1062, `val_resmarg` L1077-1080; `val_opres` and `val_rps` are absent for the SMR), divided by `pvf_onm` = 1/`crf` to be annual (L332; `e_solveprep.gms` L124-127). `lcoe_built` is one year of cost per MWh in 2044: `crf` x capital (with the financing and tax-credit multiplier) + fixed O&M + (VOM + heat rate x fuel price) x generation, over generation (L264-283). Both sides are 2004 $; the first-pass NVOE was about -32 2024 $/MWh (UON `ref` 3 GW). INFERENCE: this is a 2044 snapshot of the value of the last MW, not the whole plant over its life. Options when taken up: keep the 2044 NVOE with that label; add a later-year value from `gen_h` x `reqt_price`; or use 04f only.
